## Shared policy and limits

- **cache:** Download audit is not installation proof. Existing client caches, local imports, lockfiles/direct URLs and build-script fetches can evade this library without the independent network boundary. Never report complete install control or cooldown from a registry setting. [d2](https://github.com/Fir3st/sanjbox/blob/afae1ca7dfe78f03d5006c42b6b01093772eba0c/spikes/s5-gateway/NPM.md), [d5](https://github.com/Fir3st/sanjbox/blob/9ddb62e2efde534d7057a1ce01aa9bd942156ee8/spikes/s5-gateway/TYPED-REGISTRIES.md), [plan](https://github.com/Fir3st/sanjbox/blob/afae1ca7dfe78f03d5006c42b6b01093772eba0c/PLAN.md)
- **d1-limits:** HTTP/1.1 only, one request/connection; no HEAD, HTTP/2, WebSocket, upgrade, compression, chunked requests or half-close. Default 16 KiB headers, 1 MiB request, 4 MiB response, 32 listener connections; 10 s request, 120 s session. Upstream caps: 8 operations, 5 s DNS, 10 s connect, 15 s I/O, 120 s operation, 32 MiB SSE, 64 KiB event. Cancellation must cooperate; no hard kill guarantee. [d1](https://github.com/Fir3st/sanjbox/blob/afae1ca7dfe78f03d5006c42b6b01093772eba0c/spikes/s5-gateway/README.md)
- **d5-limits:** Proposed only: default 4 MiB metadata/artifact, 10,000 PyPI files, 4 operations, 90 s lifetime, 1,024 PyPI audit records; Git request at most 1 MiB. No redirects or cache. Absolute monotonic deadline rejects late values but awaits noncooperative children; no hard runtime-kill guarantee. [d5](https://github.com/Fir3st/sanjbox/blob/9ddb62e2efde534d7057a1ce01aa9bd942156ee8/spikes/s5-gateway/TYPED-REGISTRIES.md), [d5-deadline](https://github.com/Fir3st/sanjbox/blob/9ddb62e2efde534d7057a1ce01aa9bd942156ee8/spikes/s5-gateway/Sources/SanjboxGatewayCore/AsyncIO.swift)
- **identity:** F0.7 identity types, scopes and revocation remain unresolved. Real accounts, private registries, publish and live API credentials are unsupported. Per-zone CA authenticates the server, not client UID/session; S3/S3b/S8/D7 evidence is still required. [decisions](https://github.com/Fir3st/sanjbox/blob/afae1ca7dfe78f03d5006c42b6b01093772eba0c/docs/DECISIONS.md), [d3](https://github.com/Fir3st/sanjbox/blob/afae1ca7dfe78f03d5006c42b6b01093772eba0c/spikes/s5-gateway/MODEL-API.md), [d5](https://github.com/Fir3st/sanjbox/blob/9ddb62e2efde534d7057a1ce01aa9bd942156ee8/spikes/s5-gateway/TYPED-REGISTRIES.md)
- **model-limits:** Synthetic key only. Four-field text Messages request; no system/tools/thinking/media or non-streaming. Default 32 KiB request, 1,024 max_tokens, 256 KiB output, 4,096 events, 2 operations, 60 s cooperative lifetime, 10 attempts/60 s and 1,024 audit records. Budget is finite local units, not money; HTTP 200 before lazy debit failure is not completion. [d3](https://github.com/Fir3st/sanjbox/blob/afae1ca7dfe78f03d5006c42b6b01093772eba0c/spikes/s5-gateway/MODEL-API.md)
- **npm-limits:** 4 MiB packument/tarball; 10,000 versions; 4 operations; 90 s deadline; 3 redirects; 32-entry/16 MiB byte cache; 1,024 audit records. Strong SRI, known publish time and fresh authorization before every issuance. Baseline deadline race is corrected only by provisional ca4e50d, so bounded means configured/cooperative, not a baseline hard deadline guarantee. [d2](https://github.com/Fir3st/sanjbox/blob/afae1ca7dfe78f03d5006c42b6b01093772eba0c/spikes/s5-gateway/NPM.md), [d5-deadline](https://github.com/Fir3st/sanjbox/blob/9ddb62e2efde534d7057a1ce01aa9bd942156ee8/spikes/s5-gateway/Sources/SanjboxGatewayCore/AsyncIO.swift)
- **passthrough:** Unsupported in baseline and proposed D5. No opaque TLS, CONNECT, transparent proxy or unrestricted destination exists. Same-host OAuth/API or Git endpoint collisions must stay denied, including after a typed rejection. [d1](https://github.com/Fir3st/sanjbox/blob/afae1ca7dfe78f03d5006c42b6b01093772eba0c/spikes/s5-gateway/README.md), [d5](https://github.com/Fir3st/sanjbox/blob/9ddb62e2efde534d7057a1ce01aa9bd942156ee8/spikes/s5-gateway/TYPED-REGISTRIES.md), [plan](https://github.com/Fir3st/sanjbox/blob/afae1ca7dfe78f03d5006c42b6b01093772eba0c/PLAN.md)
- **trust:** Only public per-zone CA material may enter a client. Preserve certificate and hostname validation with a client-scoped trust configuration; no verify=false, strict-ssl=false, global trust install or insecure-host exception. HTTP examples are loopback fixture surfaces, never a claim of zone authentication. [d3](https://github.com/Fir3st/sanjbox/blob/afae1ca7dfe78f03d5006c42b6b01093772eba0c/spikes/s5-gateway/MODEL-API.md), [d1](https://github.com/Fir3st/sanjbox/blob/afae1ca7dfe78f03d5006c42b6b01093772eba0c/spikes/s5-gateway/README.md), [plan](https://github.com/Fir3st/sanjbox/blob/afae1ca7dfe78f03d5006c42b6b01093772eba0c/PLAN.md)
- **typed:** Only registered mounts and validated operations. No catch-all, CONNECT, alternate provider/account or protocol fallback; a documented client endpoint setting does not implement its protocol. [d1](https://github.com/Fir3st/sanjbox/blob/afae1ca7dfe78f03d5006c42b6b01093772eba0c/spikes/s5-gateway/README.md), [d2](https://github.com/Fir3st/sanjbox/blob/afae1ca7dfe78f03d5006c42b6b01093772eba0c/spikes/s5-gateway/NPM.md), [d3](https://github.com/Fir3st/sanjbox/blob/afae1ca7dfe78f03d5006c42b6b01093772eba0c/spikes/s5-gateway/MODEL-API.md), [plan](https://github.com/Fir3st/sanjbox/blob/afae1ca7dfe78f03d5006c42b6b01093772eba0c/PLAN.md)
