## C-003 boundary and blockers

Claude subscription, Codex ChatGPT and OpenCode OAuth require **opt-in per area** and a **closed, reviewed domain allowlist for that integration/provider**. TLS passthrough inserts no key. The token lives in the area and is assumed compromisable; its account permissions are not limited by the area. Opaque TLS cannot distinguish a foreign account/token or stop project data leaving through allowed provider domains. **Full R3 is not met under this accepted exception.**

No actual provider domain list, account scopes or disable/delete revocation procedure is supplied by this inventory. OpenCode OAuth provider selection is also unreviewed. Missing reviewed domains and revocation block implementation readiness; per-area enforcement, exact client compatibility and live evidence are unverified. S5 must measure the provider-domain exfiltration consequence and record it as C-003, never as a full R3 pass. All other R3 tests remain unchanged.

API-key modes retain typed host-gateway custody and insertion. The OAuth exception is not a fallback for a typed rejection, another client, another provider, GitHub API or an unlisted integration. Resolving same-host OAuth/typed routing requires review; this report does not create a route.
